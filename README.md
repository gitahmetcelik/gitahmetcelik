### 🧭 Hakkımda / About

- 🔭 Şu anda **Spring Boot tabanlı, olay-güdümlü backend sistemleri** (Postgres + RabbitMQ) ve **Unity ile metin tabanlı bir yaşam-simülasyon RPG'si** üzerinde çalışıyorum.
- 🌱 **Flutter/Dart** ile mobil uygulama tasarımına da zaman ayırıyorum.
- 🛠️ Dayanıklı (resilient), gözlemlenebilir (observable) ve bakımı kolay sistemler kurmayı önemsiyorum.
- 💬 Backend mimarisi, oyun tasarımı veya mobil geliştirme üzerine konuşmaktan memnuniyet duyarım.
